# Clarity Architect — global-mkts.com

Executive site for Zeeshan Sabri (ClarityOS / Global Markets Technologies). This repository is the source of truth. The GitHub repo `zsabri19/version-7` is a stale August snapshot and is not this site.

Live host: [https://global-mkts.com](https://global-mkts.com)

Canonical host is the apex **`global-mkts.com`**. `www.global-mkts.com` and `architect.global-mkts.com` are aliases. Both 301 to `https://global-mkts.com/...`. The architect subdomain is not canonical.

Cloudflare Pages project name: `version-7`. Pages twin: `version-7-9yj.pages.dev`.

This tree is also connected to the [Lovable](https://lovable.dev) project `7ec5c9f5-0719-4eda-b516-6e4529a293ed`. Commits on the connected branch show up in that editor. Do not force-push.

## Stack

- TanStack Start (React 19) + Vite + Tailwind CSS 4
- Nitro preset `cloudflare-pages` (`vite.config.ts`). Build output is the Pages layout (`dist/_worker.js` plus static files)
- Worker entry: `src/server.ts` (canonical redirects, `/robots.txt`, `/sitemap.xml`, R2 media)
- Illustrated memoir: static HTML in `public/memoir/` (not the React route tree)
- Package manager: **bun** (`bun.lock`, `bunfig.toml`)

## Local development

Requires [Bun](https://bun.sh).

```sh
git clone https://github.com/zsabri19/architectv8.git
cd architectv8
bun install
bun run dev
```

```sh
bun run build
bun run preview
bun run lint
```

`src/routeTree.gen.ts` is generated by the TanStack Router Vite plugin during `bun run dev` / `bun run build`. Do not edit it by hand. After adding or deleting a file in `src/routes/`, run a build so the tree is regenerated.

Node 22 can run the local smoke checks without a browser:

```sh
node --experimental-strip-types scripts/smoke-stabilization.ts
```

## Content pipeline

**One source of truth.** No script regenerates `src/lib/site-data.ts`.

Investigation of `scripts/` (see [scripts/archive/content-engine/README.md](scripts/archive/content-engine/README.md)):

- `content_engine_db.py` created a local SQLite file. It does not write the site.
- `content_loop.py` wrote draft JSON under `scripts/output/` from that database. Those drafts were not published.
- `extract_memoir.py` is a one-off Windows extractor aimed at `src/lib/memoir/bodies.ts`, which no route renders.
- `package.json` never called any of them. `vite build` does not run them.

Decision: the engine is retired and archived. `scripts/output/` and `*.db` are gitignored. The committed SQLite file is gone.

How an edit reaches production:

1. React pages, frameworks, articles, and SEO copy: edit `src/lib/site-data.ts`.
2. Illustrated memoir (the pages at `/memoir/*.html`): edit `public/memoir/`. Keep the existing `<!-- gmt-ga4 -->` block (`G-Z9BFJP96Q4`) in each HTML file. The React shell in `src/routes/__root.tsx` carries the same id. Deleting `scripts/inject-memoir-ga4.py` does not remove analytics, because nothing regenerates those HTML files.
3. `bun run build`, review, then deploy Pages project `version-7` after the smoke test. A CMS is not wired. Do not add a second generator.

## Redirect map

Implemented in `src/lib/redirects.ts` and mirrored in `public/_redirects`. Status is 301 unless noted. Alias hosts rewrite to `https://global-mkts.com` in the same hop.

| From | To |
| --- | --- |
| `www.global-mkts.com`, `architect.global-mkts.com` | apex, path preserved |
| `/read`, `/read/` | `/memoir/index.html` |
| `/read/<rest>` | `/memoir/<rest>` (photo renames still apply) |
| `/book`, `/memoir` | `/memoir/index.html` |
| `/book/chapter-NN-<slug>` | `/memoir/ch-NN-<slug>.html` when that chapter exists, else the memoir cover |
| Older `/book/chapter-*` slugs | the mapped chapter in `src/lib/redirects.ts` |
| `/advisory` | `/connect` |
| `/architect`, `/executive-profile` | `/the-architect` |
| `/dispatch` | `/newsletter` |
| `/index.html` | `/` |
| `/assets/cover.png` | `/assets/cover.jpg` |
| Placeholder memoir photo filenames | final filenames (`PHOTO_RENAMES`) |

`/robots.txt` and `/sitemap.xml` are served by the worker. Sitemap locations are `https://global-mkts.com/...`.

## Media

Large MP3s, MP4s, the magazine PDF, other PDFs at least 1 MB, photos at least 500 KB, and generated spoken-word files are not in the working tree. The worker serves them from R2 binding `MEDIA` when the request path is in `src/lib/r2-media-manifest.ts`. Upload and binding steps are in [docs/media-r2.md](docs/media-r2.md).

`git filter-repo` is a later, coordinated history rewrite. It is not part of this branch. A force-push would also rewrite the Lovable project history.
